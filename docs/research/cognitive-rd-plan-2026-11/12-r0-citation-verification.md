# 12. R-0: verification of the DeepSeek review's external citations (2026-11-08)

**Method.**
- Each citation was looked up in its primary listing (ACL Anthology, arXiv abstract page, NeurIPS / ICML / AAAI / WWW
  pages), with search-engine summaries used only to find it.
- Recorded for each: existence, authors, venue and status, the actual claim, and limits.
- Not done: no paper was reproduced, and full PDFs were not read end to end. Quantitative claims are **as reported by
  the authors' abstracts**.
- Dataset and code licences were **not** checked. Check each before any use.

**Status values:**
- **VERIFIED**: exists at the stated venue, and the claim matches.
- **VERIFIED, SCOPE DIFFERS**: exists, but the review's description omits a material limit.
- **PREPRINT**: exists, not peer-reviewed or published at the stated venue.
- **NOT FOUND**: none were not found.

## 2. Corrections to the review's claims

| Review statement | Correction |
| --- | --- |
| Human Emotion Verification by Action Languages is "Cambridge, 2026" | A preprint **under consideration** at a Cambridge journal; not published |
| Think² "shows" a threefold self-correction increase | An **unreviewed preprint** claim on 8B models |
| AgentMemBench "provides a unified, reproducible benchmark" | A **single-author preprint under submission**; reproducibility assets are claimed but unreviewed |
| ES-MemEval evaluates five core memory capabilities | Correct, but specifically in **long-term emotional-support** dialogue, which the review omits and which raises its relevance |
| Third-Person Appraisal Agent "simulates human emotional reasoning through … reappraisal" | Correct, but the reappraisal phase is **trained by reinforced fine-tuning**; not transferable without fine-tuning |
| CRSA yields better collaborative behaviour | Shown on **referential games and template doctor–patient dialogs** only |
| MASC detection gains | Figures differ between versions (8.47% arXiv v1 vs 7.8% in Findings); multi-agent setting only |

## 3. What changes in the plan

1. Citations 2, 4, 6, 9, 10, 11 and 13 may now be cited **with the limits above**. Citations 3, 7 and 12 stay
   PREPRINT (not support). Citations 1, 5 and 8 apply only conceptually.
2. **No design decision changes.** R-0 *strengthens* two existing choices:
   - deterministic appraisal first (CoRE shows LLM appraisals are unstable and misaligned);
   - measuring behaviour rather than model self-report (the ToM position paper).
3. **Experiment design gains two verified patterns:**
   - the **cue → later-trigger** structure (LoCoMo-Plus) for E-2/E-6;
   - **obsolete-memory penalty** scoring (Memora FAMA) for E-8 and reappraisal.
4. **Candidate external suite:** ES-MemEval (EvoEmo), after a licence check, as an *outside* sanity check for E-2/E-8.
   The LILITH-specific suites stay primary.
