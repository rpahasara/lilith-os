5. Local follow-up tracker

Also inspect this local file if it exists:
~/.hermes/automation/productivity/followups/followups.json

Include active follow-up items with status "waiting".

For each active follow-up:
- Show the title
- Show why it is being tracked
- Show the due date if one exists
- If no due date exists, say that clearly
- Do not invent a due date
- If something appears stale or worth chasing, recommend that I follow up, but do not send anything

Follow-up due-date interpretation:

- If a follow-up has due_date, treat it as an exact date.
- If it has due_window_start and due_window_end, treat it as an expected window, not an exact deadline.
- For a future window, report it like:
  "Expected window: 31 Aug–6 Sep."
- Do not recommend chasing the person before the expected window ends unless another email indicates urgency.
- If the expected window has passed and the follow-up is still status "waiting", recommend following up.
- Never invent an exact due date from a window.
- Respect due_confidence when describing certainty.
